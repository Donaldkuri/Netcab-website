# NETCAB Website

## About
NETCAB provides networking and cabling, voice and data solutions, 
VSAT connectivity, and PABX systems for businesses and organisations 
in Kokopo and East New Britain, Papua New Guinea.

## Target Audience
Businesses, organisations, and institutions in Kokopo and East New 
Britain needing reliable telecommunication infrastructure services.

## Pages
- Home (index.html)
- About (about.html)
- Services (services.html)
- Gallery/Projects (gallery.html)
- Contact/Booking (contact.html)

## Assessment 3 Update

This site has been extended from Assessment 2 into a responsive, styled website using HTML5 and CSS3.

**What was added:**
- External stylesheet (`css/styles.css`) with CSS variables for colour, typography and spacing
- Flexbox layouts: sticky footer, service cards on the homepage, contact page layout
- CSS Grid layouts: services grid, gallery grid
- Responsive navigation and page layouts across mobile, tablet and desktop breakpoints
- Media queries at 900px and 600px
- Responsive images, consistent buttons/cards/forms, visible focus states
- New service added: Starlink Router Installation

**Responsive breakpoints:**
- Desktop: > 900px
- Tablet: 601px – 900px
- Mobile: ≤ 600px

**Testing:**
- Accessibility: Lighthouse Accessibility audit, 100/100 on all 5 pages (see `screenshots/` folder)
- Responsive testing: screenshots at mobile (375px), tablet (768px) and desktop (1440px) widths for every page, in `screenshots/`
- Cross-browser testing: verified in Chrome and Edge
