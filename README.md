# NETCAB Website

## About
NETCAB provides networking and cabling, voice and data solutions, 
VSAT connectivity, and PABX systems for businesses and organisations 
in Kokopo and East New Britain, Papua New Guinea.

## Target Audience
Businesses, organisations, and institutions in Kokopo and East New 
Britain needing reliable telecommunication infrastructure services.

## Pages
- Home (index.html)
- About (about.html)
- Services (services.html)
- Gallery/Projects (gallery.html)
- Contact/Booking (contact.html)
